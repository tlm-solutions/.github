## Hi, we are Transit Live Mapping Solutions

Enhancing openness and promoting access to Dresden public infrastructure data by surprise backuping the radio communications since 2022.

We are a small group of students — Marenz, Tassilo and 0xA. What started as a small side project during lockdown ended up getting somewhat out of hand and turned into this.

The goal was simple: collect communications between public transport and traffic lights in real time, and make it available in a straightforward way. The result is a live map showing vehicle positions and related information.

https://map.tlm.solutions/

The data is collected via a network of radio receivers distributed across the city, listening to the broadcasts sent by public transport vehicles. The setup mainly targets Dresden, but the software was written in a way that does not hard-code the city.

The project is largely finished. The infrastructure is still running and occasionally maintained, but this is now mostly a snapshot of what we built at the time.
